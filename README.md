# mmm

Automated Tibanna gas mining platform

## Development

* Install [Python 3.13+](https://www.python.org/)
* Install [Poetry](https://python-poetry.org/docs/)
* Install [Docker Desktop](https://docs.docker.com/get-started/get-docker/)

```sh
# clone
git clone https://github.com/tanaabased/mmm.git
cd mmm

# setup
make setup

# activate venv
eval $(poetry env activate)

# verify LEAN
lean --help
```

## Testing

```sh
# lint/format
make lint
```
